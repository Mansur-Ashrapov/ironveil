Iron Veil                
Краткое описание
Кооперативный dungeon crawler с жесткой привязкой к классу персонажа. Группа игроков исследуют “подземелье”, где встречают враждебных мобов, ловушки.

Общее описание
Игроки управляют выбранными персонажами, вид сверху(top-down), могут передвигаться, могут использовать способности персонажей. В процессе игры игрокам предстоит исследовать уровень, сражаться с мобами, повышать уровень персонажа, сразить главного босса.

Убийство босса локации

КЛАССЫ
KNIGHT
Описание: самый базовый класс, играя за которого, игрок обязан защищать слабых в команде, так как имеет высокий класс защиты. В сражении первым встречает удары врагов. Имеет средний урон. Имеет способность “агрить” мобов на себя, чтобы собрать их в кучу либо защитить другого игрока. Умеет делать короткий дэш или уворот.
Контроль:
* перемещение 
* дэш
Атаки:
* обычный ближний удар
* сильный удар или Очень сильный удар имеющий долгую перезарядку
Способности:
* отвлечение мобов на себя
* защитная стойка








MAGE 
Описание: класс поддержки, умеющий лечить по команде, имеет слабую самонаводящуюся атаку и “ульту”. Самый малый класс защиты в команде, из-за чего обязан держаться за “KNIGHT”. Может кастовать “ульту” в виде “луча смерти” которая имеет большой урон, но бьет только в сторону которую смотрит.
Контроль:
* перемещение 
Атаки:
* самонаводящаяся дальняя атака
* очень сильный удар (ульта) по площади имеющий долгую перезарядку
Способности:
* лечение себя и союзников
* временное усиление союзников 


ROGUE 
Описание: класс разведки, средний класс защиты, быстрое перемещение, усиленный урон врагам, которые атакуют не его[b], умеет делать дэши.  Может ставить “метку” на враге, по которому будет наносится усиленный урон.[c] Имеет способность “тихий шаг”, используя которую становится невидимым для врагов.
Контроль:
* перемещение 
Атаки:
* быстрый ближний удар
Способности:
* метка увеличивающая урон по врагу
* “тихий шаг” - невидимость для врагов до первого удара
Пример сражения: группа мобов (~10 шт.) с мини-боссом атакует отряд, KNIGHT агрит мобов на себя, пока MAGE кастует ульту, ROGUE в это время ставит метку на мини-боссе. KNIGHT делает дэш в сторону, чтобы не попасть под ульту MAGE, после этой атаки, добивают оставшихся (2-3 обычных мобов) и мини-босса.


Игровой путь MVP:
        Игроки появляются в подземелье, пробуют использовать свои способности -> начинается исследование подземелья -> встреча первых мобов, их убийство, получение урона и xp -> первый чекпоинт -> дальнейшее исследования подземелья, повышения уровня, новые чекпоинты -> нахождение комнаты босса -> первая попытка одолеть -> смерть -> разбор ошибок, не хватает уровня, плохая слаженность, непонятны атаки босса -> следующие попытки -> победа


Прокачка персонажей
* У каждого персонажа есть уровень.
* При убийстве мобов и боссов вся команда получает общий опыт, который распределяется на каждого.
* При повышении уровня игроку автоматически усиливаются основные параметры + даётся выбор улучшения одного из навыков персонажа.


Параметры, которые растут автоматически с уровнем
* Здоровье
* Урон
* Защита

ТЕХНИЧЕСКИЙ СТЕК
* Движок: Godot Engine 4.5
* Мультиплеер: Steam Networking + ENet
* Паттерн: авторитарный сервер с синхронизацией состояния

--------------------------------------------------------------------------------
СИСТЕМА ИГРОКА (PlayerBase)
--------------------------------------------------------------------------------
Реализованные характеристики:
* Здоровье (health) с максимумом и регенерацией
* Мана (mana) с максимумом и регенерацией  
* Выносливость (stamina) с максимумом и регенерацией
* Базовый урон (base_damage)
* Сопротивление урону (damage_rezistance)
* Уровень и опыт

Управление:
* Перемещение в 8 направлениях (WASD)
* Использование способностей (Space, ПКМ)
* Поворот спрайта в сторону движения

Система прокачки:
* При убийстве мобов игроки получают опыт
* При достижении порога опыта происходит повышение уровня
* При повышении уровня автоматически растут:
  - Здоровье (+20 за уровень)
  - Выносливость (+20 за уровень)  
  - Мана (+20 за уровень)
  - Урон (+5 за уровень)
* При повышении уровня открывается UI выбора способности для улучшения
* Поддержка очереди улучшений (если получено несколько уровней сразу)

Система респавна:
* При смерти игрок становится невидимым
* Запускается таймер респавна (5 секунд)
* После таймера игрок возрождается на точке спавна
* Полное восстановление здоровья, маны и выносливости

--------------------------------------------------------------------------------
СИСТЕМА СПОСОБНОСТЕЙ (Ability)
--------------------------------------------------------------------------------
Базовая система:
* Кулдаун способностей
* Стоимость маны и выносливости
* Проверка возможности использования (достаточно ресурсов + прошёл кулдаун)
* Интеграция со звуковой системой

Система прокачки способностей:
* Каждая способность имеет уровень (0-5)
* При улучшении уменьшается кулдаун (-10% за уровень)
* При улучшении уменьшается стоимость маны и выносливости (-8% за уровень)
* Уникальные описания улучшений для каждой способности

Реализованные способности:

1. SWORD (Удар мечом) - для класса Knight
   * Ближняя атака
   * Урон = базовый урон игрока
   * Кулдаун: 0.7 сек
   * Стоимость: 5 выносливости, 0 маны
   * Направление удара зависит от направления движения/взгляда

2. TAUNT (Провокация) - для класса Knight
   * Переключает агро всех мобов в радиусе 500 единиц на использующего
   * Длительность агро: 5 секунд
   * Даёт +20% сопротивления урону на время действия
   * Кулдаун: 10 сек
   * Стоимость: 15 выносливости, 10 маны
   * Визуальный эффект расширяющегося круга

3. FIREBALL (Огненный шар) - для класса Mage
   * Дальнобойная самонаводящаяся атака
   * Летит в направлении движения игрока
   * Наносит урон врагам при попадании
   * Кулдаун: 1.5 сек
   * Стоимость: 5 выносливости, 20 маны
   * Синхронизируется через MultiplayerSpawner

4. BEAM (Луч смерти / Ульта) - для класса Mage
   * Мощная атака по площади
   * Наносит двойной урон (base_damage × 2)
   * Бьёт в направлении взгляда
   * Кулдаун: 2.5 сек
   * Стоимость: 10 выносливости, 25 маны

--------------------------------------------------------------------------------
СИСТЕМА МОБОВ (MobBase)
--------------------------------------------------------------------------------
Базовые характеристики:
* Здоровье
* Опыт за убийство
* Скорость передвижения

ИИ мобов:
* Поиск ближайшего игрока в радиусе агрессии (300 единиц)
* Преследование цели до максимальной дистанции (800 единиц)
* Переключение цели при потере текущей
* Периодическое обновление цели (каждые 30 кадров)
* Поворот спрайта в сторону цели

Система агро:
* Обычное агро на ближайшего игрока
* Принудительное агро (force_aggro) - для способности Taunt
* Таймер принудительного агро с автоматическим сбросом

Система отбрасывания (Knockback):
* При получении урона моб отбрасывается от источника
* Сила отбрасывания: 200 единиц
* Длительность: 0.35 секунды
* Плавное затухание эффекта

Типы мобов:
* Slime (Слайм) - базовый ближний моб

--------------------------------------------------------------------------------
БОСС
--------------------------------------------------------------------------------
Характеристики:
* Здоровье: 500
* Урон в ближнем бою: 25
* Урон от специальной атаки: 60
* Радиус ближней атаки: 120
* Дистанция отступления: 250
* Радиус телепорта: 600

Система фаз:
* Фаза 1 (>50% HP): кулдаун атаки 3 сек, кулдаун ульты 12 сек
* Фаза 2 (≤50% HP): кулдаун атаки 2 сек, кулдаун ульты 8 сек

Состояния босса:
* IDLE - ожидание, выбор следующего действия
* TELEPORT_IN - телепортация к цели
* MELEE_ATTACK - ближняя атака
* RETREAT - отступление после атаки
* SPECIAL_MARK - установка метки на игрока
* SPECIAL_STRIKE - специальная атака по отмеченной цели

Особые механики:
* Телепортация к игроку для атаки
* Смена цели после каждой атаки (переключается на другого игрока)
* Специальная атака с меткой:
  - Босс выбирает цель и ставит визуальную метку
  - Метку можно перехватить способностью Taunt
  - После задержки (1 сек) босс телепортируется и наносит усиленный урон
* При смерти босса срабатывает условие победы

--------------------------------------------------------------------------------
МУЛЬТИПЛЕЕР
--------------------------------------------------------------------------------
Архитектура:
* Авторитарный сервер (вся логика на сервере)
* Клиенты отправляют команды, сервер валидирует и синхронизирует
* RPC для синхронизации состояния

Steam интеграция:
* Инициализация Steam API
* Проверка владения игрой
* Получение Steam ID и имени пользователя
* Steam Networking для соединений

Синхронизируемые данные:
* Позиция игроков
* Параметры (здоровье, мана, выносливость, опыт, уровень)
* Использование способностей
* Состояние мобов и босса
* Звуковые эффекты

--------------------------------------------------------------------------------
ИНТЕРФЕЙС (UI)
--------------------------------------------------------------------------------
HUD игрока:
* Полоса здоровья с динамическим обновлением
* Полоса маны
* Полоса выносливости
* Полоса опыта
* Таймер респавна при смерти

UI прокачки способностей:
* Появляется при повышении уровня
* Список способностей с текущим и следующим уровнем
* Описание улучшений для каждой способности
* Клик для выбора способности

ЗВУКОВАЯ СИСТЕМА (SoundManager)

* Синглтон для глобального доступа

* Поддержка 2D и глобальных звуков
* Кэширование загруженных аудиофайлов
* Система заглушек для отсутствующих звуков

Реализованные звуки:
* player_hurt - игрок получает урон
* player_death - смерть игрока
* player_level_up - повышение уровня
* ability_sword - удар мечом
* ability_beam - луч
* ability_fireball - огненный шар
* ability_taunt - провокация
* mob_hurt - моб получает урон
* mob_death - смерть моба
* ui_click - клик по UI
* ui_upgrade - улучшение навыка
